Run it locally

One command: clones the repo, installs Bun if missing, installs deps, and launches the app.

git clone https://github.com/0xxmemo/harry.git && cd harry && { command -v bun >/dev/null || { curl -fsSL https://bun.sh/install | bash; export PATH="$HOME/.bun/bin:$PATH"; }; } && bun install && bun run app

macOS / Linux. Harry is a Tauri desktop app, so the first launch needs a Rust toolchain (rustup) and compiles for a few minutes.
